# Disease Prediction from Medical Data

## Objective

The objective of this project is to predict the class of a medical case using machine learning techniques.

## Dataset

The project uses the Breast Cancer Wisconsin dataset available through Scikit-learn.

The dataset contains medical measurements related to breast tumors.

## Machine Learning Algorithms

Two classification algorithms are used:

- Logistic Regression
- Random Forest

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib

## Project Steps

1. Load the medical dataset
2. Check and understand the data
3. Split the data into training and testing sets
4. Scale the features
5. Train the Logistic Regression model
6. Train the Random Forest model
7. Make predictions
8. Compare model performance
9. Display a confusion matrix

## Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score

## Results

The performance of Logistic Regression and Random Forest is compared using the evaluation metrics mentioned above.

## How to Run

Open `Disease_Prediction.ipynb` using Google Colab or Jupyter Notebook and run the cells from top to bottom.

## Note

This project is created for educational and machine learning purposes. It should not be used as a medical diagnostic system.
